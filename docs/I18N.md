# Internationalization (el / en): Agent Manual

Status: read this before adding or changing any user-facing string.

## Mental model

1. **Two locales, one catalog.** Every string lives in the `strings` object
   (`src/i18n.ts:5`). The startup language is **detected**, not hardcoded:
   Greek when `navigator.languages` contains an `el` entry or the timezone is
   `Europe/Athens`, otherwise English (`detectLang`, `src/i18n.ts:119`). An
   explicit toggle choice persists in `pdf-fixer:lang` and overrides detection.
2. **Two ways to render text:** static DOM carries `data-i18n` /
   `data-i18n-aria` and is filled by `applyStatic()` (`src/i18n.ts:173`);
   dynamic text calls `t()` (`src/i18n.ts:144`).
3. **Toggling re-applies and broadcasts.** `setLang()` updates `<html lang>`,
   runs `applyStatic()`, then notifies subscribers (`src/i18n.ts:152`); rows
   subscribe and re-render (`src/components/result-row.ts:91`). The info dialog
   needs no subscription: it is always in the DOM with `data-i18n` nodes, so
   `applyStatic()` updates it even while hidden.

## Source of truth vs derived

- **Stored:** the `strings` catalog (`src/i18n.ts:5`), the in-memory `current`
  language (`src/i18n.ts:130`), and an explicit user choice in `localStorage`
  key `pdf-fixer:lang` (`src/i18n.ts:3`). Detection is only a fallback when that
  key is absent; do not persist the detected value.
- **Derived:** all rendered copy, `<html lang>`, and `document.title` (from
  `docTitle`, `src/i18n.ts:180`).
- **Rule:** never hardcode a translated literal in a component, and never read
  the language from `localStorage` outside `src/i18n.ts`.

## Invariants (MUST NOT)

1. Every key exists in BOTH locales. `StringKey` is derived from the `el`
   catalog (`src/i18n.ts:117`), so a missing `en` key fails `npx tsc --noEmit`.
2. Static text MUST carry `data-i18n` (text) or `data-i18n-aria` (aria-label) AND
   be seeded with `t()` at build time. Do not set a literal then rely on
   `applyStatic` alone; the first paint must already be translated.
3. Dynamic text MUST use `t()`; interpolate with `{name}` placeholders via the
   second arg (`t('pages', { count })`), never string concatenation.
4. `setLang()` is the ONLY mutator of the current language (`src/i18n.ts:152`).
   Do not write `localStorage` or `document.documentElement.lang` elsewhere.
5. `applyStatic()` MUST run after components are mounted (`src/main.ts:21`),
   otherwise `data-i18n` nodes created later stay in the detected locale.
6. Every `onLangChange()` subscription MUST be unsubscribed in `destroy()`
   (`src/i18n.ts:165` returns the unsubscribe; used at
   `src/components/result-row.ts:111`).
7. `<html lang>` is the source for a11y/SEO and drives the flag swap in CSS.
   `setLang` keeps it in sync; do not edit it directly.

## Worked example: the same key in both locales

| Key | `el` | `en` |
|---|---|---|
| `title` | Επιδιόρθωση PDF | PDF Repair |
| `pages` | `{count} σελίδες` | `{count} pages` |
| `fixedMany` | `Διορθώθηκαν {count} προβλήματα...` | `Fixed {count} structural problems...` |
| `langButton` | `EN` (target) | `ΕΛ` (target) |
| `infoTitle` | Τι κάνει αυτή η εφαρμογή; | What does this app do? |

## Common tasks (recipes)

- **Add a string** -> add the key to BOTH locale objects (`src/i18n.ts:5`); tag
  the node `data-i18n`/`data-i18n-aria` and seed it with `t()`.
- **Use a dynamic string** -> `t(key, { count })`; never build sentences by
  concatenation (word order differs by language).
- **Add a language** -> (1) extend the `Lang` union (`src/i18n.ts:1`); (2) add a
  locale object to `strings`; (3) teach `detectLang` (`src/i18n.ts:119`) and the
  stored-value check (`src/i18n.ts:134`) about it; (4) add the toggle target in
  `src/components/header.ts:23`; (5) add its flag to `FLAGS` in
  `src/lib/flags.ts` and the CSS swap in `src/style.css`. The typecheck enforces
  catalog parity.
- **Change the toggle label** -> `langButton` is the language you switch TO, so
  each locale names the other.
- **Change the browser tab title** -> `docTitle`, not `title` (`title` is the
  visible `h1`).

## Verification checklist

1. `npx tsc --noEmit` passes (proves both catalogs have the same keys).
2. `npm run build && node scripts/e2e.mjs` for regressions after string changes.
3. Manual: clear `localStorage`, load with a Greek browser or `Europe/Athens`
   timezone and confirm Greek; load otherwise and confirm English. Click EN/ΕΛ
   and confirm `<html lang>`, the flag, title, header, drop zone, toggle and
   auto-download label all switch; open the info dialog, switch language and
   confirm its copy switches; process a PDF and toggle again to confirm the
   existing row re-translates; reload to confirm `pdf-fixer:lang` persists.
